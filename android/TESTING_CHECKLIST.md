## 📊 后端日志检查

播放测试时，同时观察后端日志：

```bash
# 实时查看日志
tail -f data/logs/app.log

# 或查看最近的日志
tail -n 100 data/logs/app.log
```

**关键日志验证**：
- [ ] 看到 `playback.plan` 日志（表示成功生成播放计划）
- [ ] 看到媒体请求日志（包含 `X-Juku-Viewer` 请求头）
- [ ] 没有 `playback.failed` 或 `media.failed` 错误
- [ ] 看到播放进度上报日志

## 🔍 故障排查提示

如果播放失败，按以下顺序检查：

1. **网络连接**
   ```bash
   # 从 Android 设备访问后端
   curl http://192.168.1.108:8999/api/ui/viewer
   ```

2. **ViewerId 是否设置**
   - 在 MainScreen.kt 的 `openDrama` 函数添加日志
   - 打印 `repository.apiClient.getViewerId()`

3. **播放 URL 是否正确**
   - 在 MainScreen.kt 打印 `activeVideoUrl`
   - 检查是否为完整的 URL

4. **ExoPlayer 错误**
   - 在 PlayerScreen.kt 添加 ExoPlayer 错误监听器
   - 打印详细错误信息

5. **后端日志**
   - 检查是否收到播放请求
   - 检查是否有 401/403/410 错误
   - 检查 FFmpeg 是否正常工作
